## 확인된 drift

| 항목 | 분류 | 판정 |
|---|---|---|
| Codable/serde concrete JSON shape | 허용 | 외부 interchange artifact가 아니라 각 언어의 persistence representation이다. 필드 의미와 불변식 round-trip을 보존한다. |
| 두 번째 stream consumer | 허용 | Swift는 명시적 실패 event, Rust는 ownership으로 컴파일 단계에서 차단한다. |
| Runtime injection surface | 허용 | Rust는 HTTP/clock/vault를 명시적 port로 공개한다. 제품 orchestration 책임은 추가하지 않는다. |
| Codex continuation·output limit·retention gate | 수정 완료 | Rust가 Swift와 같이 Codex의 미검증 기능을 전송 전에 거부하고, Responses/Gemini continuation은 명시적 retention opt-in에서만 허용한다. |
